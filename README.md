# This landing-page implemented a feedback form, animation, and smooth appearance of elements. The site's dynamics create a lively effect but do not distract, providing a pleasant user experience.

🔗 **Demo** : https://zhuridochka.github.io/Maven-show/home.html

## What is implemented
- 1:1 layout to the layout — indents, fonts, colors
- Adaptive from 1920px to 320px
- Interactive elements in pure JS, without libraries
- Semantic markup, without unnecessary divs
- Animation

## Maven - It is a modern one -page site dedicated to health and well -being. The project has an attractive design, rich functionality and adaptive elements that provide excellent custom experience.

## Technologies used:
  HTML: Semantic marking to provide structured and available content.",
  SCSS: SCSS stylization to ensure flexibility and convenience in maintaining styles.
  JavaScript: The interactivity and dynamics of the site, including the implementation of the Burger menu, sliders and running lines.
